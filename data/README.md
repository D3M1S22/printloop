# data/

Not versioned, except this file.

- `data/testset/`: generated by `uv run printloop testset`. One case per folder (C0–C7) with the patched project (`project.3mf`), the sliced 3MF to print (`slice/sliced.3mf`) and the `manifest.json` with the ground truth (induced parameter, expected patch). After printing, the photos go into `data/testset/<case>/photos/` (protocol in [docs/printloop/02_DATA_STRATEGY.md](../docs/printloop/02_DATA_STRATEGY.md) §3.1); then `uv run python -m printloop.eval diagnosis`.

Working cases (photos, patches, G-code, audit) live in `runs/cases/<id>/`, also not versioned. Files discarded when going back to an earlier step are archived in `runs/cases/<id>/discarded/`.
Public datasets (CAXTON, CC BY 4.0) are not redistributed.
