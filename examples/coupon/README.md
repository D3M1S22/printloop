# Coupon di prova PrintLoop

`coupon_p1s_pla.3mf`: piastra 60×20×2 mm, due pilastri 8×8×13 mm e un ponte di 44 mm in cima (modello nostro, solo parallelepipedi). In ~12 minuti su P1S mostra bridge, stringing tra i pilastri, pareti e primo layer.

Impostazioni: profili di sistema BambuStudio `Bambu Lab P1S 0.4 nozzle`, `0.20mm Standard @BBL X1C`, `Bambu PLA Basic @BBL P1S 0.4 nozzle` (con `filament_density` fissata a 1,26, che da CLI non viene ereditata). Piatto: Cool Plate (dal profilo di sistema); se si stampa su un altro piatto, cambiarlo nello slicer prima di generare il test set.

Rigenerare: `uv run printloop coupon`.
