Generated by `printloop-ft download | prepare | dedup | build`, not versioned.

```text
data/
├── raw/<source>/          # original downloads (download.json = source, version, licence, date)
├── interim/               # normalized images (RGB JPEG, long side ≤ 1280) + manifest.jsonl + dedup.json
└── processed/<build_id>/  # train/val/test JSONL ({id, image, defects, primary, source, group}) + stats.json
```
